## Быстрый запуск

Крупные таблицы и исходный архив признаков хранятся через **Git LFS**.

```bash
git lfs install
git clone https://github.com/Nitospb/haktramv.git
cd haktramv
git lfs pull
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python reproduce_best.py --output outputs/submission_reproduced.csv
```

Последняя команда восстанавливает лучший прогноз из сохранённых компонентов
без переобучения и проверяет побайтное совпадение с подтверждённым файлом.
SHA-256: `b8f8238db449a7401f9d63543c60288b018ed9a1e991ba04745825f82d056524`.
Готовый CSV можно использовать и без установки Python.

## Лучший вариант v8

1. Базовый профиль по маршруту, часу, типу дня и летнему/учебному периоду,
   с поправкой на недавний уровень маршрута.
2. Ансамбль моделей с погодой, календарём и режимами движения задаёт форму
   распределения потока по дням и часам.
3. Его месячный объём согласуется с базовым прогнозом отдельно по маршрутам.
4. Смешиваются 75% согласованного прогноза и 25% базового; учитываются отмены.

## Проверка и повторное обучение

Обучение проводилось на Mac Studio: 16 CPU, 128 ГБ RAM. По умолчанию код
читает `data/`; другой каталог задаётся переменной `TRAM_DATA_DIR`.
Для повторения цепочки v8:

```bash
export TRAM_DATA_DIR="$PWD/data"
export OPENBLAS_NUM_THREADS=2
python research_v2.py
python feature_models.py
python ensemble_features.py
python service_models.py
python event_experts.py
python reconcile_forecasts.py
```

Переобученные результаты будут в `outputs/v2/`, `outputs/v4/` и далее;
опубликованный снимок результатов находится в `outputs/studio/`.
Численные результаты переобучения могут немного отличаться между платформами.
Скрипты повторного обучения не заменяют `outputs/submission_best.csv`.

Периоды локальной проверки: июль–август, август–сентябрь, сентябрь–октябрь;
октябрь дополнительно рассматривается отдельно. Эти периоды частично
перекрываются и уже использовались для подбора. Они **не являются новой
независимой проверкой**. Использовались предоставленные ретроспективные
погодные и событийные признаки. У маршрута 5 нет обучающей разметки,
поэтому его прогноз остаётся нулевым.
