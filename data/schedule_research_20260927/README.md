# Поминутные расписания и признаки предложения транспорта

Маршруты задачи: **1, 5, 7, 11, 12, 17, 25, 26, 28, 50**.

## Найденные данные

- `minute_schedule_archived_9_routes.csv.gz`: 133012 записей «рейс — остановка — прибытие/отправление» для всех целевых маршрутов, кроме №5. 4272 шаблона рейсов, оба направления, идентификаторы календарей и даты действия. Извлечены из уже предоставленного пользователем GTFS; это не новый независимый источник.
- `terminal_departures_archived.csv`: начальное и конечное время каждого рейса. Время выражено минутами от начала дня обслуживания, поэтому может превышать 1440.
- `archived_service_calendar.csv`: дни недели и интервалы действия календарей GTFS.
- `route5_current_minute_schedule.csv`: 26116 времён по 16 остановкам в каждом направлении на все семь дней недели. Номер дня: понедельник 0, воскресенье 6. Направление A — от Рижской к Белорусскому вокзалу, B — обратно. Источник не предоставляет trip_id; порядок времён на разных остановках нельзя автоматически считать соответствием рейсов.
- `route5_current_hourly_departures.csv`: отправления №5 от начальной остановки по часам, направлениям и дням недели.
- `archived_supply_hourly_2025.csv`: сетка 10 маршрутов × 365 дней × 24 часа. `scheduled_mean_moving_trams` — сумма длительностей всех рейсов внутри часа, делённая на 60. Это среднее число одновременно движущихся по расписанию вагонов, без отстоя и оборота. `scheduled_terminal_departures` — отправления от начальных остановок обоих направлений. `schedule_day_covered` отличает отсутствие расписания от нулевого ночного движения; непокрытые значения сохранены пустыми.

## Источники и ограничения

1. [Mobility Database mdb-3226](https://mobilitydatabase.org/feeds/gtfs/mdb-3226), категория **Community Feed**. Указывает файл производителя `https://greens3.transitpdf.com/files/sourcedata/moscow-official.zip`. Имеющийся у нас архив получен 30.06.2026, внутренняя дата файлов — 27.05.2025. Дата окончания календаря 2030 не доказывает неизменность движения до 2030. Таблицы `calendar_dates.txt` нет, поэтому праздничные исключения не восстановлены. Майский снимок не отражает все ремонты и последующие изменения.
2. [Поминутное расписание №5, понедельник, направление A](https://kudikina.ru/msk/tram/5/A?d=1). Агрегатор указывает источником публичные данные Мосгортранса. Получены все 14 сочетаний дня недели и направления; URL, дата получения и хеш HTML сохранены в `web_sources.json`. **Дата действия не указана: соответствие декабрю 2025 не подтверждено.** HTML оставлен локально; повторное получение — `python3 fetch_route5_schedule.py`.
3. [Дептранс, 16 декабря 2025](https://transport.mos.ru/mostrans/all_news/127652): начало работы №5 Рижская — Белорусский вокзал; №9 и с510 прекращают работу с 17 декабря. Это подтверждённое событие внутри целевого периода, но не архив точного расписания.
4. [Официальная страница расписаний](https://transport.mos.ru/transport/schedule) найдена, прямой запрос в этой сессии вернул блокировку HTTP 477. Из неё точное расписание не извлечено.

По сообщению пользователя, организаторы разрешают использовать данные из прогнозного периода и ретроспективные сведения. Поэтому здесь ограничение практическое: фактический почасовой выпуск ноября–декабря 2025 пока не найден, а текущая таблица не подтверждает исторические значения.

## Применение к модели

Признаки обычного GTFS уже входят в `feature_models.py`. Дополнительно подготовлена физически интерпретируемая оценка среднего числа вагонов в движении. Эксперимент `fleet_forecast_study.py` предсказывает наблюдаемое по транзакциям число вагонов, затем посадки на вагон. Это разные величины: вагон без транзакций не виден, а несколько сменявших друг друга вагонов могут учитываться в одном часе.

Пересборка: `python3 prepare_schedule_supply.py`. Проверены охват девяти маршрутов, 14 страниц №5 с 16 остановками, отсутствие дублей ключей и сохранение суммарных вагоно-минут при разбиении рейсов по часам. Время GTFS после 24:00 переносится на следующие календарные сутки. Для №5 сохранено исходное время часов; принадлежность полуночных отправлений предыдущему дню обслуживания неизвестна.
