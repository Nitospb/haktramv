# История работы трамвайных маршрутов, 2025

Источник — официальный публичный архив Дептранса `https://t.me/s/DtOperativno`.
Сбор: `../collect_tram_service_2025.py`. Ручная нормализация событий:
`../build_tram_service_2025.py`. Часовой пояс всех нормализованных событий — Москва.

## Покрытие

- Просмотрен непрерывный диапазон архива от ноября 2024 до января 2026: 261 страница, 5045 сообщений, 0 неудачных страниц.
- За 2025 сохранено 4423 сообщения, 276 из них с упоминанием трамваев.
- Нормализовано 52 записи календаря (38 исходных объявлений, 52 уникальных источника вместе с восстановлением/обновлением). Одна новость может дать несколько записей для разных часов/маршрутов.
- Отдельно 47 сообщений о внеплановых сбоях на целевых маршрутах; 45 сопоставлены с сообщением о восстановлении по прямой ссылке-ответу.
- Почасовая сетка: 87600 строк = 10 маршрутов × 365 дней × 24 часа.

Это максимально доступная выборка из просмотренного архива, **не гарантия всех отмен Москвы**. Удалённые сообщения, сведения только на картинках, объявления в других источниках и исходные версии отредактированных постов могут отсутствовать. Неустановленные маршруты/длительности не выдумываются.

## Файлы

- `events.json`, `events_reviewed.csv`: проверенные интервалы, маршруты, часы, дни недели, источники, публикации и восстановления.
- `incidents.json`: аварийные задержки и связанные с ними восстановления.
- `route_hour_features_full_calendar.csv`: полный календарь с учётом всех найденных объявлений года.
- `posts_2025.json`, `tram_posts_2025.json`: тексты и метаданные источников.
- `review_queue.json`: что включено, что требует дополнительной проверки или относится к другим маршрутам.
- `coverage.json`, `fetch_errors.json`: отчёт сбора. `pages_v2/` — воспроизводимый кеш.
- `pages/` — первичный кеш, не используется: в нём цитата ответа могла подменять основной текст. Исправленный сбор использует только `.js-message_text`, не `.js-message_reply_text`.

## Правила интерпретации

Полная отмена отделена от изменения части трассы, снижения частоты и переноса остановок. Объединение 13+50 летом — изменение трассы, **не нулевой маршрут50**. Метро, для которого трамвай26 указан альтернативой, — отдельный сетевой фактор, не отмена трамвая.

Сентябрьская отмена50 завершается восстановлением15ноября; декабрьские ограничения7/50 — ночные и только в выходные по исправленному сообщению24106. Маршрут5 запускается16декабря; наличие флага не решает задачу оценки его пассажиропотока без истории.

Интервалы дат полуоткрытые: start включительно, end исключительно. Доли неполных часов рассчитываются по пересечению. Для последних ночных рейсов в отсутствие точного окончания используется явно помеченная граница04:00 как приближение эксплуатационной ночи, не доказанное время открытия. У событий «до окончания мероприятия» ограничение до конца того же дня — верхняя граница; точная длительность неизвестна. Эти ограничения отмечены в `notes`.

Для инцидента без восстановления кодируется только час сообщения. Для связанных сообщений длительность считается от публикации предупреждения до публикации восстановления: фактическое начало/окончание могло отличаться. Это признаки наблюдаемого сообщения, не телеметрия движения.

При режиме as-of окончание, узнанное из более позднего восстановления, не доступно раньше его публикации. В конкурсном варианте **по явному указанию пользователя разрешён полный календарь ноября–декабря**. Метки целевой переменной после обучающей границы не используются.

У нормализованных исходных объявлений медиана опережения даты начала —1день, максимум8дней; это не доказывает, что более ранних объявлений не было. Нельзя называть весь архив известным за два месяца.
