# Данные признаков для прогноза трамвайных посадок

Снимок подготовленных данных проекта на 26 сентября 2026 года.
Архив содержит данные и описания, без Python-кода, обученных моделей,
сабмитов, OOF-предсказаний и исходных многогигабайтных транзакций/хешей карт.
MANIFEST.json перечисляет каждый файл, его исходное расположение относительно
проекта, размер и SHA-256. Заголовки CSV/схемы Parquet сохранены без изменений.

## Состав

| Каталог | Данные |
|---|---|
| 01_connectivity_and_uav | Сообщения о БПЛА, ограничения аэропортов, сообщения о связи, периоды возможных ограничений, почасовые признаки по маршрутам |
| 02_repairs_and_service | Проверенный календарь трамвайных ремонтов, отмен, изменений трассы, остановок, инцидентов; исходные сообщения и источники |
| 03_weather_and_calendar | Погода по часам/дням/ячейкам/районам, климатология, координаты и веса ячеек; праздники, рабочие дни и переносы |
| 04_education | Каникулы, учебные периоды и приближённые признаки университетского календаря |
| 05_stops_and_nearby_objects | Остановки, геометрия маршрутов, школы, вузы, метро, ТЦ и прочие объекты; расстояния и пересадки |
| 06_schedules | Расписания по остановкам, время проезда, GTFS, подготовленные почасовые признаки расписания и объектов |
| 07_transaction_derived | Исторические агрегаты работы вагонов/валидаторов, признаки задержек загрузки, сравнение валидаторов и тарифные группы |
| 08_external_seasonality | Московский месячный пассажиропоток, сезонный профиль 2022–2024 и экспериментальные транспортные данные других городов |

## Ограничения и смысл данных

- Это все перечисленные подготовленные источники признаков, а не одна
  универсальная обучающая матрица. Часть лагов, взаимодействий и признаков
  дальности прогноза рассчитывается моделью для конкретной даты начала
  прогноза. Кэши таких повторяющихся обучающих матриц сюда не включены.
- Основные ключи: route/date/hour для маршрут-часовых таблиц; date для
  календаря; stop_id и координаты для остановок; zone/cell/district для
  погоды. Названия конкретных ключей смотрите в заголовках исходных файлов.
  Нельзя соединять таблицы только по дате без проверки их детализации.
- Диапазоны дат различаются: городской ряд 2019–сентябрь 2025; исходный
  районный календарь содержит историю с 2016 года; подготовленные оперативные
  признаки в основном январь–октябрь 2025; событийные признаки — 2025 год.
- Региональные сообщения о БПЛА и аэропортах — косвенные сигналы, а не
  подтверждённая карта отключений интернета. Запуск белых списков не означает
  непрерывные ограничения. Районные отключения не выдуманы.
- Ремонты относятся прежде всего к трамвайным путям/движению. Полного реестра
  дорожных работ и отдельного достоверного архива дорожных пробок в проекте нет.
- Погода — исторические значения/реанализ и климатология, не архив прогнозов,
  выпущенных за два месяца. В исходном районном CSV часть значений общей
  центральной ячейки повторена по районам: проверяйте district_weather_source.
- Учебные признаки включают прокси, а не расписания каждого учебного заведения.
- Возле остановки сохранено не более 10 ближайших объектов в радиусе 1500 м;
  это не исчерпывающая инвентаризация всех объектов. attendance может быть
  неизвестной или иметь исходные единицы; это не измеренные посадки.
- GTFS — статический снимок. Исторические признаки распространяли его
  недельный профиль на 2025 год; это не доказанное реальное расписание каждого
  дня. Переносы рабочих дней и исключения требуют отдельной проверки.
- Каталог 07 вычислен из транзакций и может содержать число успешных оплат,
  идентификаторы техники и близкие к target показатели. Используйте только
  прошлое относительно forecast origin. Не присоединяйте фактическое число
  валидаторов/посадок целевого будущего часа как доступный заранее признак.
- Задержки input_date_time не являются достоверной разметкой офлайн-сбоев:
  поле официально ненадёжно. Сравнение валидаторов — эвристика, не акты ремонта.
- Полный календарь событий использует ретроспективную информацию. Файлы
  asof_oct31 и hindsight явно разделены. При строгом тестировании учитывайте
  published_at и дату доступности каждого источника.
- Экспериментальные источники других городов отделены: они не являются
  московскими наблюдениями и не имеют гарантированного положительного эффекта.
- Сохранённые source_notes.md могут упоминать код/модели и старые оценки:
  эти артефакты не входят в архив. Описания приложены ради происхождения,
  единиц и ограничений данных, не как инструкция запускать отсутствующий код.

CSV, Parquet, JSON и GeoJSON сохранены в оригинальных форматах. Исходные
данные не исправлялись и не пересчитывались при упаковке.
