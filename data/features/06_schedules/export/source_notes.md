# Расписание трамваев Москвы

Источник: набор GTFS `mdb-3226` из Mobility Database. Снимок скачан 30.06.2026, но файлы внутри источника датированы 27.05.2025. Поэтому это плановое архивное расписание, а не прогноз движения в реальном времени.

## Файлы

- `moscow_tram_schedule_overview.xlsx` — удобный обзор маршрутов и типичного времени движения по остановкам.
- `moscow_tram_full_schedule_by_stop.csv` — полное расписание: каждый плановый рейс и каждая его остановка с временем прибытия и отправления.
- `moscow_tram_route_stop_travel_times.csv` — компактное время по остановкам для каждого направления и варианта трассы.
- `moscow_tram_routes.csv` — список маршрутов.
- `moscow_tram_gtfs_filtered.zip` — исходный GTFS, отфильтрованный только до трамваев.
- `metadata.json` — размеры, контрольные суммы и статистика набора.

## Как посчитать время между любыми остановками

В компактной таблице вычтите `typical_minutes_from_start` остановки посадки из того же поля остановки назначения. Например, если у посадочной остановки значение 12, а у следующей нужной 20, плановое время поездки составляет 8 минут.

В полном расписании используйте один `trip_id`: вычтите `minutes_from_trip_start` посадочной остановки из значения остановки назначения. Так расчёт будет относиться к конкретному рейсу.
