# Недельные лаги и обучение развёрнутой цепочки

Основной файл остаётся `outputs/submission_best.csv`, подтверждённый скор
сайта **0,89214**. По последующей просьбе пользователя создан отдельный
экспериментальный [submission_consistency_c5.csv](outputs/submission_consistency_c5.csv)
из модели с сильным согласованием путей. Его результат сайта пока неизвестен.

## Какая гипотеза проверена

Речь об обучении всей траектории, а не только повторном запуске модели,
обученной на следующую неделю. Каждое предсказание добавляется в историю,
следующие шаги используют его, а градиент ошибки последнего блока проходит
через предыдущие предсказания. Код не обрывает этот граф через `detach()`.

Для одних и тех же исторических дат проверены:

- обычная модель на +7 дней, рекурсивно применяемая дальше;
- прямой прогноз всего 61-дневного горизонта;
- обучение через полную рекурсивную цепочку с шагом 7 дней;
- та же цепочка с дополнительным прямым прогнозом и штрафом за их расхождение;
- увеличение веса последних 7 дней с 1 до 2;
- отдельное обучение всей цепочки с шагом **один день** и согласованностью.

Рекурсивные модели дополнительно проверены с обоими шагами inference: 1 и 7.
У обычной модели на +7 возраст прогноза при каждом вызове сбрасывается,
как при её обучении; она не получает ранее невиданный возраст всей цепочки.

Сеть предсказывает логарифмическую поправку к недельному аналогу:
`prediction = (weekly_base + 30) * exp(residual) - 30`.
Смещение 30 позволяет восстанавливаться после нулевого или отменённого рейса.
Оптимизируется MAE **в исходном масштабе числа посадок**, чтобы учитывать
метрику соревнования. Применяются текущие календарные/погодные признаки,
их отличие от недели-аналога и внешний сезонный индекс только 2023–2024.

Функция потерь согласованной модели:

`L = (MAE(recursive, y) + 0.5*MAE(direct, y) + λ*MAE(recursive, direct)) / (1.5 + λ)`.

Проверены λ = 0,1; 1; 5. Последние два значения проверены дополнительно
после обнаружения сильного расхождения путей при λ = 0,1.

Последние 7 дней имеют вес 1 или 2 в соответствующем варианте. Все 61 день
остаются в supervised loss: именно весь период оценивает соревнование.
Согласованность полезна как ограничение расхождений, однако два пути могут
согласованно ошибаться при смене сезона.

Обучение: PyTorch 2.14.0, GPU Mac Studio / MPS, общая сеть с embedding
маршрута и часа, два скрытых слоя по 64 нейрона, 60 эпох, фиксированные
начальные seed и параметры. Это одна реализация гипотезы, а не доказательство,
что любой рекурсивный подход бесполезен.

## Полученные результаты

23 даты отсечения для простых моделей (окна перекрываются); 32 обучения
нейросетей на четырёх датах отсечения. Для июля используется ровно 61 день
(1 июля — 30 августа), поэтому сравнение v8 также обрезано до тех же дат.
Октябрь — отдельная 31-дневная диагностика. Все окна ранее изучались,
результаты являются оценками разработки, независимого holdout нет.

| Модель | Июль–30 августа | Август–сентябрь | Сентябрь–октябрь | Октябрь |
|---|---:|---:|---:|---:|
| Повтор последней известной недели | 0,81475 | 0,78064 | 0,82319 | 0,88609 |
| Среднее четырёх недель, без новых фактов | 0,81811 | 0,80236 | 0,79028 | 0,90210 |
| Прямая NN на 61 день | 0,79130 | 0,76889 | 0,86472 | 0,84311 |
| Обучение цепочки +7, без согласованности | 0,55084 | 0,83446 | 0,55354 | 0,87732 |
| Цепочка +7, λ=0,1, вес конца ×2 | 0,73896 | 0,81357 | 0,63037 | 0,88588 |
| Цепочка +1, λ=0,1, вес конца ×2 | 0,71044 | 0,82260 | 0,61578 | 0,88731 |
| Цепочка +7, **λ=5**, вес конца ×2 | **0,83229** | 0,79104 | 0,83943 | 0,88784 |
| **Текущая v8** | 0,81259 | **0,88826** | **0,90571** | **0,91216** |

Недельная сезонность сильна, но перенос летнего уровня при повторении недели
и накопление поправок в нейросети существенно влияют на длинный прогноз. На сентябре–октябре простая
модель, обученная только на +7, разгонялась в рекурсии; обучение всей цепочки
и согласованность уменьшили этот эффект, однако текущий прогноз не улучшили.
Дополнительный вес последней недели не дал устойчивого выигрыша на всех окнах.

При λ=5 удалось почти свести прямой и рекурсивный пути на осеннем окне:
`Σ|recursive−direct|/Σy` уменьшилось с **0,26739 до 0,00739**; для последней
недели — с 0,49081 до 0,01477. Однако скор двух путей составил только
0,83943 и 0,83916. На июльском окне сильное согласование превысило v8,
но на трёх последующих окнах уступило, поэтому замена основной модели
не предлагается. Таблица: `consistency_strength_comparison.csv`.

Корреляция `y[t]` с фактическим `y[t-7]` на сентябре–октябре — **0,98483**,
но WAPE-score такого прогноза — **0,89068**. Этот вариант получает настоящие
обновления внутри прогнозируемого периода и поэтому непригоден для нашего
61-дневного прогноза; он сохранён отдельно как диагностический пример.

Проверки всех 32 обучений: изменение скрытых ответов не меняет прогноз
(максимальная разница 0), обучающие метки заканчиваются до даты отсечения.
Для полных 61-дневных окон проверена ненулевая производная последнего блока
по первому предсказанному блоку. Подробные аудиты сохранены рядом с моделями.

## Проверка структуры входных данных

- Пересечения ключей `route/date/hour` в готовых train/test labels нет.
- Шаблон submission содержит полную сетку 14 640 ключей и не содержит row_id.
- В его baseline всего 28 различных чисел; для одного маршрута и часа значение
  одинаково на всех датах. Дневных колебаний будущего target он не раскрывает.
- Полностью прочитан сырой `test.csv`: **13 391 571** записей, последняя
  фактическая валидация — **2025-11-01 01:37:43**.
- За пределами октября есть **615** записей, из них **562** успешных, только
  первые два часа 1 ноября. Остальные ноябрьские и декабрьские даты отсутствуют.
- Два operational CSV содержат 12 агрегированных строк того же хвоста.
  Остальные проверенные производные таблицы заканчиваются октябрём.
- Эти пограничные наблюдения не использовались в обучении, подборе или
  исправлении текущего submission. Восстановление всего hidden target из
  проверенных файлов не найдено. Это не устанавливает причину чужого 0,95754.

## Файлы и воспроизведение

### Экспериментальный сабмит по просьбе пользователя

Модель `consistent7_c5_tail2` переобучена на Studio с теми же настройками:
60 эпох, коэффициент согласованности 5, двойной вес последних 7 дней.
Доступная история заканчивается 31 октября; начало прогноза — 1 ноября,
длина — 61 день. В CSV выгружен недельный рекурсивный путь, соответствующий
строке с локальным скором 0,83943 в таблице выше.

Файл содержит 14 640 строк в порядке исходного шаблона. Проверены уникальность
ключей, даты, целые неотрицательные прогнозы и неизменность результата при
подмене скрытых ответов. SHA-256:
`85146c703c97d950e065deb728f6cdbcc61b0b64b6ecc2916a34ba5c56612f5e`.

На ноябре–декабре расхождение прямого и рекурсивного путей составляет
0,86685% **от среднего прогнозируемого объёма**. Это не WAPE-score: фактический
объём скрытого периода неизвестен. Сохранены модель, оба пути и отчёт в
`outputs/studio/v11_consistency_submission/`.

Команда создания на Studio:

```bash
OPENBLAS_NUM_THREADS=2 .venv/bin/python make_consistency_submission.py --device mps
```

### Исторические проверки

- `weekly_baselines.py`: недельные аналоги и диагностический rolling с фактами.
- `unrolled_weekly.py`: дифференцируемая цепочка, прямой путь и consistency loss.
- `outputs/studio/v11_weekly/`: метрики, 32 модели, прогнозы и проверки.
- `outputs/weekly_input_audit/`: аудит временных границ, только агрегаты.
- `outputs/studio/v11_weekly/forecast_trajectory.png`: траектория на осеннем окне.

```bash
python -m pip install -r requirements-recursive.txt
python weekly_baselines.py
python unrolled_weekly.py --origins 181,212,243,273 \
  --modes step7,direct61,rollout7,consistent7,consistent7_tail2,consistent_daily_tail2,consistent7_c1_tail2,consistent7_c5_tail2 \
  --epochs 60 --device mps
```

На машине без MPS используется `--device cpu`; численные результаты могут
немного отличаться. Скрытых целевых значений ноября–декабря для сравнения нет.
