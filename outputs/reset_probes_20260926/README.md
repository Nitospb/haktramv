# Пять быстрых диагностических сабмитов перед сбросом

Собраны 26.09.2026 из сохранённых прогнозов без переобучения. Опора — v8 с публичным score 0,89214. Все CSV содержат 14 640 строк в исходном порядке; значения целые неотрицательные. Лучший файл не менялся.

Рекомендуемый порядок загрузки: **04 → 02 → 01 → 03 → 05**. Файл 04 улучшил три из четырёх ранее изученных локальных окон; это диагностические пробы, а не подтверждённые улучшения сайта. Присылать номер файла вместе с результатом.

В 03 и 04 прибавка компенсируется в соответствующих оставшихся датах. Округление с распределением остатков сохраняет суммы в точности. Для 03 октябрьское окно из одного месяца не проверяет гипотезу: прогноз совпадает с v8. Локальные окна перекрываются и уже использовались в разработке. Результаты сайта приведены ниже; каноническая история — `outputs/leaderboard_results.json`.
